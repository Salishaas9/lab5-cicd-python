\# Лабораторная работа №5: GitLab CI/CD для Python-проекта



\## Описание

Минимальный Flask-сервер с настроенным CI/CD пайплайном на GitLab.



\## Структура проекта

\- `app.py` - Flask-сервер

\- `requirements.txt` - зависимости

\- `tests/` - тесты

\- `.gitlab-ci.yml` - конфигурация пайплайна



\## Запуск локально

pip install -r requirements.txt

python app.py



\## Пайплайн

Пайплайн включает этапы:

1\. Установка зависимостей

2\. Линтинг (flake8)

3\. Статический анализ (bandit)

4\. Проверка уязвимостей (safety)

5\. Тестирование (pytest)

6\. Сборка
